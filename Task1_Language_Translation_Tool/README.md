# AI Language Translation Tool

**Task 1 — CodeAlpha AI Internship**

A desktop GUI application that translates text between 15 languages using the free MyMemory Translation API. Built with Python and Tkinter.

## Features

- **15 Languages** — English, Spanish, French, German, Italian, Portuguese, Russian, Japanese, Korean, Chinese, Hindi, Arabic, Turkish, Dutch, Polish
- **Swap Languages** — One-click source/target swap
- **Copy Output** — Copy translated text to clipboard
- **Text-to-Speech** — Listen to translations aloud
- **Translation History** — View all past translations
- **No API Key Required** — Uses free MyMemory API
