# AI FAQ Chatbot

**Task 2 — CodeAlpha AI Internship**

An NLP-powered chatbot that answers Frequently Asked Questions by matching user queries to the most relevant FAQ using **TF-IDF vectorization** and **cosine similarity**.

## Features

- **NLP Pipeline** — Tokenization, stop-word removal, TF-IDF
- **Cosine Similarity Matching** — Finds the best FAQ answer
- **Confidence Scoring** — Shows match accuracy percentage
- **10 FAQ Topics** — Hours, passwords, refunds, shipping, pricing, and more
- **Interactive CLI** — Chat directly in the terminal

## How to Run

```bash
# No external dependencies required!
python faq_chatbot.py
